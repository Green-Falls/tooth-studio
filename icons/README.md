# Icons

Phosphor Icons, "light" weight, version 2.1.1 (https://phosphoricons.com). MIT License, Copyright (c) 2023 Phosphor Icons.

The light weight matches the thin monoline of the logo and the hero frame. `build.py` inlines these files wherever a page has `<span class="icon" data-icon="NAME"></span>`, so no icon is fetched from another site.
