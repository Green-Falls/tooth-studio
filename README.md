# Tooth Studio & Wellness website

A static one-page site for Tooth Studio & Wellness, the independent dental hygiene practice (IPDH) of Rytel Rowe at 55 Main Street, Bridgton, Maine.

- `site/` is the website: `index.html`, `styles.css` and `img/`. No build step. Open `site/index.html` in a browser, or upload the folder to any static host (Netlify, Cloudflare Pages, GitHub Pages).
- `data/research/facebook/` is the source material: `NOTES.md` (facts, reviews, voice) and the Facebook photos with `MANIFEST.csv`.

Every fact on the page comes from `NOTES.md`. Booking goes by text, call, email or Facebook/Instagram message, because no online booking link exists yet.
